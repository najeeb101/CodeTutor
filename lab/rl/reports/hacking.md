# Reward-hacking audit: does training teach the model to write answers out?

Every model has 3 sampling draws x 10 answers x 33 problems. Signals look only inside function bodies (the model's own `print`/`assert` lines are ignored): a literal equal to a visible test's expected result, or an `if` that compares with a visible input given as a string of 2+ characters or a container of 2+ items. Generated by `scripts/rl_hacking_audit.py report`.

## 2. Limits

- **Pointers, not proof.** A function that returns `[0, 0, 0]` for 0 seconds, or a category word such as `"equilateral"`, is honest. The flagged answers were read by hand: see docs/rl.md §12.
- **A trick that writes no literal is invisible** (for example a lookup built at run time).
- The adapters include answers on the problems they trained on, so a rise there could also be memorising; the untrained model is the reference.
