# Eval noise: the same model, two sampling draws

Each model was evaluated twice on all 33 problems (10 answers each, temperature 0.8, Docker). The draws differ only in `seed_base` (0 and 1000). Nothing else changed, so every difference below is luck of the sampling. Generated by `scripts/rl_after.py noise`.

## 1. The same model twice

| Model | Problems | pass@1 draw 0 | pass@1 draw 1000 | Mean difference | SD of differences |
|---|---|---|---|---|---|
| untrained 0.5B | 33 | 0.636 | 0.667 | +0.03 | 0.161 |
| adapter c | 33 | 0.724 | 0.691 | −0.03 | 0.114 |
| adapter b | 33 | 0.721 | 0.697 | −0.02 | 0.125 |

The spread (SD) of the per-problem differences is the noise of one problem's pass@1 change. A before -> after change has this noise before any training.

## 2. Is the fold's held-out change above the noise?

Rule (written before the runs): the change counts as above noise only if its size is larger than the 95% band `1.96 x SD / sqrt(m)` (SD from the untrained model's two draws, m = held-out problems), in both draws.

| Fold | Held-out problems | Change draw 0 | Change draw 1000 | Noise band | Verdict |
|---|---|---|---|---|---|
| c | 8 | +0.04 | 0.00 | ±0.112 | within noise |
| b | 8 | 0.00 | −0.01 | ±0.112 | within noise |

SD used: 0.161 (per-problem pass@1 difference, one fold's size m).

## 3. Limits

- Two draws is the minimum: the SD is itself uncertain.
- This is evaluation noise only. **Training noise** (another training seed) is still unmeasured; it can be larger.
- The band treats problems as independent and the SD as the same for every problem.
- The rule fixes what counts as above noise; it does not prove transfer.
