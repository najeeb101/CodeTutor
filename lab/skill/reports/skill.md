# Problem difficulty and student skill from first attempts

Two estimators on the same data: plain **pass rates** (a problem's difficulty is how often it fails; a student's skill is the share of problems solved) and a **Rasch** model (the chance of a first-try solve is `sigmoid(skill - difficulty)`, one number per student and per problem, fitted together; fixed prior spread 1.0, nothing tuned). Both see only the database's view; the simulation's true skills and difficulties are used only to score them. Generated by `scripts/skill.py report` (docs/integrity.md §3).

## 3. When data is missing

Mean Pearson r over 20 seeded deletions. Pass rates can mislead when the missing answers are not random (a problem the weak students skipped looks easier than it is); Rasch compares like with like. Measured here: Rasch is ahead in 8 of 8 comparisons, by 0.01 to 0.04 correlation points. A real but small gain on this data.

| Class | Responses deleted | Left | Difficulty r: pass rate / Rasch | Skill r: share / Rasch |
|---|---|---|---|---|
| seed 0 | 30% deleted at random | 70% | 0.78 / 0.80 | 0.87 / 0.88 |

## 5. What these numbers can and cannot say

- **The simulator follows Rasch.** A student solves with chance `sigmoid(skill - difficulty)`
  (docs/integrity.md §1.1), so this checks that our fitting code recovers the numbers a
  Rasch-shaped world makes. It does not show that real students follow Rasch.
- **Complete data flatters the baselines.** Almost every simulated student tried almost every
  problem, so pass rates do nearly as well as Rasch in §2. §3 is the fairer test.
- **First try is a choice.** Later tries are practice, so they are left out. A student who
  fixes the bug on try 2 counts as "not solved" here.
- **Cheating rows bend the skill estimate.** A pasted answer makes a student look more able.
  Dropping the rows the integrity checks flag helps the skill estimates (§2). For difficulty
  it changes little, because the flagged set also holds honest students and removes data. The
  checks themselves are imperfect (docs/integrity.md §2.4).
- **Estimates, not grades.** Skill numbers are for teachers to see who needs help, never to
  mark a student.
